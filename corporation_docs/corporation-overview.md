# Corporation Overview

ERSELMETZ AI CORPORATION is an actual software system implementing a
virtual/simulated AI organization. The organization is the system's domain
model and operating concept.

The current application includes a local Python command-line system and a
FastAPI interface. Its implemented foundations include Corporation and Node
identity, an Orchestrator, Employees, technical Agents, Provider/Model
boundaries, Tasks, Projects, and bounded task activity. These foundations are
not a claim that every capability is production-complete.

The internal Documentation Portal reads approved Markdown files from the
repository-root `corporation_docs/` directory. It is separate from the public
project documentation website in `docs/` and is not an AI-managed knowledge
system.
