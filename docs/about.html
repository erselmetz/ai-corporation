About the project

About

ERSELMETZ AI CORPORATION is an actual software system implementing a virtual/simulated AI organization.

Project

The Corporation is software for modeling and operating an AI organization. Its current implementation is a local Python CLI with orchestration, task management, Employees and Agents, a Provider/Model boundary, routing, persistence, and bounded integration foundations.

This website

This public documentation website is a lightweight Node.js project located in the docs/ directory of the main repository. It is part of the repository but not part of the Corporation runtime. The site is independently runnable and can serve the documentation while the Corporation is offline.

It is a presentation-only site: it does not import or call the Corporation application, access its database or registries, invoke Ollama, execute tasks, control Agents, or modify runtime state. It uses Node.js built-in modules and has no third-party runtime dependencies.

Running locally

cd docs
npm start
# Open http://localhost:3000

npm test

Requires Node.js 18 or newer. The website can also be hosted as static files; its HTML, CSS, and browser-side JavaScript are self-contained in this directory.

Documentation scope

This site complements the root project README rather than replacing it. Implementation status and limits are based on the repository's current project documentation and may change as the project evolves.
