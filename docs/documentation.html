Documentation

A guide to the Corporation's implemented foundations and documented direction.

Current implementation

The application is currently a local Python command-line system. It models Corporation and Node identity, Employees and technical Agents, a Provider/Model boundary, persisted Tasks and Projects, deterministic task routing, lifecycle logging, and dry-run inspection. Ollama is the current Provider integration.

Tasks 1–36 are documented as completed milestones. “Completed” refers to the implemented milestone foundation; it does not imply that each area is a production-complete subsystem. The task roadmap gives concise implementation descriptions and separates future work.

Implementation caveats

  • Employee, Agent, Provider, Corporation, and Node registries are in-memory; broad administrative persistence is not implemented.
  • Tool and approval foundations are not wired into task execution as enforcement gates.
  • TaskRegistry does not currently persist or reload project_id.
  • Integration proposals, analysis, evaluation, sandbox records, and preparation records are in-memory foundations.
  • The public documentation site is a separate Node.js presentation app and does not connect to the Corporation runtime.
