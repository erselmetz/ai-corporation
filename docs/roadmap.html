Controlled evolution

The intended direction for external-source work is staged: discover, analyze, evaluate, propose, prepare or execute within a sandbox, test, review, approve, integrate, and monitor. Implemented source preparation is not equivalent to execution or approval. Unrestricted autonomous self-modification is not the current design.
