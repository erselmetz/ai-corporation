ERSELMETZ AI CORPORATION

ERSELMETZ AI CORPORATION is an actual software system implementing a virtual/simulated AI organization.

The software models an organization and provides its current runtime capabilities. This site documents the implementation, its boundaries, and a roadmap that distinguishes completed foundations from planned work.

Current scope: Tasks 1–57 are implemented foundations, including the authorized FastAPI resource APIs, read-only Corporation dashboard and management pages, the internal Markdown Documentation Portal and curated Updates / Changelog page, plus in-memory Conversation and Message records with a controlled message lifecycle and an Individual Employee Chat Core service with fixed Employee/Agent targets. No chat interface, provider response flow, persistence, or chat-to-Task workflow is included. Browser sign-in is not configured, so protected data/actions require an authenticated session; Tasks 58–100 remain planned, not claims about current functionality.

Chat Context — Task 57

Added caller-supplied context bounded to 8192 UTF-8 bytes per conversation, with atomic replacement, isolation, and clearing on successful closure; no retrieval, persistence, provider calls, or chat API/UI. Trusted Core callers enforce authorization and relevance before supplying text; caller-held copies cannot be revoked. The Documentation Portal remains file-based and read-only.

This standalone Node.js documentation site is part of the Corporation repository, but is not part of its runtime.
