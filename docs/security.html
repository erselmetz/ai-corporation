Trust and access

Security

Protected operations require explicit identity, permission, and scope.

Local owner access

Local mode uses an owner sign-in and scoped session permissions.

Fail-closed API

Without configured authentication, protected API access is rejected.

Explicit actions

Provider use, capture, and other sensitive operations require applicable authorization.

Bounded data

Media and requests have size or lifetime limits; not all local records are encrypted at rest.

Release readiness

The Windows 11 x64 installer has local acceptance evidence only. It is unsigned and is not a public stable release. No live provider/model workload or hardware-fit profile is release-verified.

App-managed capability packs are not supported: Task 134 remains deferred, and no pack installer or dynamic loader is included. Optional capabilities that require separate packages remain unavailable unless the owner installs their documented external prerequisites.

Focused regressions passed: 115 Python tests, 54 browser/Electron checks, and 15 public documentation tests. These are project-run checks, not an independent security/privacy review.

Task 170 remains planned until an independent security/privacy reviewer examines a fixed source revision and all findings are dispositioned. This page and the project’s own tests are not that independent review.

This page summarizes controls; it is not a security certification. See the task evidence for specific limits.
