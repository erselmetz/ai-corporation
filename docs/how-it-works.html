Workflow

How it works

Requests move through explicit routing and permission checks.

  1. Ask

    Send a chat message or create a task through the interface.

  2. Route

    The Orchestrator resolves the selected Agent and configured Provider/Model.

  3. Run

    The authorized operation runs within its configured limits.

  4. Review

    Inspect the response or task outcome before deciding what to do next.

Capabilities vary by configuration. A completed task status does not prove every requested outcome.
