Task lifecycle

How it works

The CLI and authorized Task API create and inspect Tasks through the Application Service. Deterministic routing and Provider execution remain Core operations.

Task flow

  1. The CLI, Task API, or small client/business adapter supplies a task description and optional routing requirement.
  2. The Application Service delegates Task creation to the Orchestrator, which creates a Task and persists its lifecycle and routing fields.
  3. The Task Router resolves an explicit Agent first, then an Employee role and associated Agent, then a required Agent capability.
  4. The Orchestrator marks the Task running and calls the selected Agent when execution is requested by the existing local runtime.
  5. The Agent uses its configured Provider and Model. Ollama is currently the only registered Provider integration.
  6. The Orchestrator records the outcome and logs completion or failure.

Routing options

task "Summarize the report" --agent local_worker
task "Summarize the report" --role "Local AI Worker"
task "Summarize the report" --capability summarization
dry-run TASK-ID [--agent ID | --role ROLE | --capability CAPABILITY]

Creation stores the requirement rather than resolving it immediately. Options are mutually exclusive. A Task without a routing requirement is allowed but cannot route unless a dry-run override supplies one.

Dry-run is an inspection

Dry-run reports the selected Employee/Agent, Provider, Model, route method, and readiness without calling a Provider. It does not change Task status, result, error, assignment, or stored route requirements. Temporary override options apply only to that routing request.

Important boundaries

  • Routing is deterministic registry lookup, not AI/LLM-based selection.
  • There is no automatic fallback Agent.
  • Tool and approval registries are standalone foundations and are not wired into task execution.
  • The website you're reading is separate from this execution flow and does not communicate with the runtime.

For component boundaries, see Architecture.
